一个经典的装饰器如下

```python
def log(text):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kw):
            print('%s %s():' % (text, func.__name__))
            return func(*args, **kw)
        return wrapper
    return decorator


@log('execute')
def now():
    print('2024-6-1')

```

其中@后面的内容与下面等同

```python
def now():
    print('2024-6-1')
now = log('execute')(now)
```

其中 decorator 的形参调用了 now 函数，保存了一份指向 now 的变量 func，然后定义了一个  wrapper 函数，这个 wrapper 函数后的 *arg(类型为tuple), **kw(类型为dict)将所有输入wrapper函数的参数打包，丢到arg和kw里，然后执行一系列的指令，最后通过 func 返回now函数原本要执行的东西。这里的 func 相当于给wrapper函数保留了一份指向原 now函数的指针，但是 now 的原函数被除名了，无法直接指向它。

```
@functools.wraps(func)
```

这一句是保留 now 函数的名字，否则新的 now 调用__name__函数就会返回 wrapper 的名字
