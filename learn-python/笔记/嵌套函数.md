1.定义一个函数的时候，可以在该函数内继续定义函数，运行外层函数时，就会定义出一个内层函数（类似与创建一个变量）

例如

```python
def outer():
    def inner():
        print("a")
    return inner()

t = outer
```

这样，t 就是一个被定义出来的一个函数

与下面的函数比

```python
def t():
    print("a")
```

上面的 t 可以读取outer函数内的参数，而下面的t不行，

2.如果内层函数没有被全局的变量调用，那么这个函数就会消失。反之，这个内层函数的所有外层函数都会被保留

3.如果外层函数定义了一个内层函数，且有返回这个内层函数，可以用 外层函数(外层参数)(内层参数) 这样的结构来返回内层函数返回的值
